# GLAMZ Family Salon Website

A modern, responsive website developed for **GLAMZ Family Salon**, a local family salon in Kochi.

This project was created as part of a Full Stack Web Development Internship task focused on solving a real business problem through web development. Instead of building a fictional application, the objective was to create a professional online presence for an actual local business.

---

## Live Demo

🔗 https://glamzfamilysalon.vercel.app

## Project Overview

GLAMZ Family Salon primarily serves customers through its physical location and local reputation. This website was designed to strengthen its digital presence by providing customers with easy access to information about services, location, business hours, and contact details.

The website focuses on:

- Building customer trust
- Improving business visibility
- Showcasing services professionally
- Providing convenient contact options
- Creating a modern and mobile-friendly experience

## Installation

Clone the repository:

```bash
git clone https://github.com/aadarshantony/FUTURE_FS_03.git
```

Navigate to the project folder:

```bash
cd glamz-family-salon
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```

# Business Pitch

## Business

GLAMZ Family Salon is a local salon offering professional grooming, beauty, haircare, and family-focused salon services.

## Problem

Many local businesses rely primarily on walk-in customers and social media platforms. Customers often struggle to find important information such as services, timings, location, and contact details quickly and conveniently.

Without a dedicated website:

- Online visibility remains limited
- Customer trust may be reduced
- Information is scattered across platforms
- Potential customers may choose competitors with stronger digital presence

## Solution

This project provides a modern, responsive, and professional website that serves as a central digital platform for the business.

The website allows customers to:

- Explore available services
- Learn about the salon
- View salon galleries
- Read customer testimonials
- Access location and contact information
- Connect directly through WhatsApp

## Benefits to the Business

- Improved credibility and professionalism
- Better customer engagement
- Increased local visibility
- Improved customer convenience
- Stronger online brand presence
- Foundation for future digital growth
